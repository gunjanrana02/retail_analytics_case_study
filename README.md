# 🛒 Retail Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing retail sales data using SQL to extract meaningful business insights. The dataset was cleaned, validated, and transformed before performing analytical queries.

The project mainly demonstrates practical SQL skills including:

* Data cleaning
* Data validation
* Customer analysis
* Sales analysis
* Customer segmentation

---

## 🧰 Tools Used

* MySQL
* SQL

---

## 🔧 Data Cleaning & Processing

The following preprocessing steps were performed before analysis:

* Resolved column encoding issues
* Handled NULL and missing values
* Removed duplicate transaction records
* Standardized inconsistent data
* Corrected pricing mismatches across tables
* Converted date columns into SQL DATE format
* Performed validation checks on sales data

---

## 📊 Sales & Business Analysis

Business-related insights generated from the dataset include:

* Product-wise sales performance
* Total quantity sold per product
* Category performance analysis
* Top 10 products by revenue
* Lowest performing products
* Daily sales trend analysis
* Month-over-Month (MoM) growth analysis

---

## 👥 Customer Insights

Customer behavior analysis performed using SQL queries:

* Identification of high-value customers
* Low-frequency customer analysis
* Repeat customer behavior tracking
* Customer loyalty analysis based on purchase duration

---

## 🎯 Customer Segmentation

Customers were segmented into different groups based on purchasing behavior:

* Low-value customers
* Medium-value customers
* High-value customers

The total customer count in each segment was also analyzed.
